## 배포 완료 기준

자동 배포는 단순히 GitHub에 코드가 올라간 상태가 아니다. 호스팅 프로젝트가 저장소에 연결되고, 빌드가 성공하며, 환경변수가 안전하게 설정되고, 배포 URL에서 실제 화면과 핵심 기능이 확인되어야 완료로 판정한다.
